1. JavaScript 기본 문법

<script>

console.log("Hello JavaScript");

</script>

JavaScript는 웹 페이지의 동작을 담당하는 프로그래밍 언어이다.

2. 변수와 자료형

let name = "Yejin";

const age = 24;
키워드 설명
let 변수 선언
const 상수 선언
var 예전 방식

3. 연산자

let a = 10;
let b = 20;

console.log(a + b);
연산자 설명
+ 더하기
- 빼기
* 곱하기
/ 나누기

4. 조건문

if(age >= 20){
  console.log("성인");
}
else{
  console.log("미성년자");
}

5. 반복문

for(let i=1; i<=5; i++){

  console.log(i);

}
반복문 설명
for 횟수 반복
while 조건 반복

6. 함수(Function)

function hello(){

  console.log("안녕하세요");

}

hello();

7. 이벤트(Event)

button.addEventListener(
  "click",
  function(){

    alert("클릭!");

  }
);

사용자의 행동(클릭, 입력 등)에 반응한다.

8. DOM 선택자

document.getElementById("title");

document.querySelector(".box");
메서드 설명
getElementById() id 선택
querySelector() 첫 번째 요소 선택

9. 배열(Array)

let fruits = [
  "사과",
  "바나나",
  "포도"
];

10. 객체(Object)

let user = {

  name:"Yejin",

  age:24

};

11. Fetch API

fetch("/data")

.then(res => res.json())

.then(data => {

  console.log(data);

});

서버와 비동기 통신을 수행한다.

12. AJAX

const xhr =
new XMLHttpRequest();

xhr.open(
  "GET",
  "/data"
);

xhr.send();

페이지 새로고침 없이 데이터를 주고받는다.

13. JSON

{
  "name":"Yejin",
  "age":24
}

서버와 데이터를 주고받을 때 사용하는 형식이다.

💡 핵심 요약

  • JavaScript는 웹 페이지의 동작을 담당한다.
  • let, const를 사용하여 변수를 선언한다.
  • 조건문과 반복문으로 흐름을 제어한다.
  • 함수는 코드를 재사용하기 위해 사용한다.
  • 이벤트는 사용자 행동에 반응한다.
  • DOM 선택자를 이용해 HTML 요소를 제어한다.
  • 배열과 객체로 데이터를 관리한다.
  • Fetch와 AJAX는 서버 통신에 사용된다.
  • JSON은 데이터 교환 형식이다.
