1. JavaScript 기본 문법

<script>

console.log("Hello JavaScript");

</script>

JavaScript는 웹 페이지의 동작을 담당하는 프로그래밍 언어이다.

2. 변수와 자료형

let name = "Yejin";

const age = 24;
키워드 설명
let 변수 선언
const 상수 선언
var 예전 방식

3. 출력문

        console.log("콘솔 출력");

        alert("알림창");

        document.write("화면 출력");
메서드 설명
console.log() 콘솔 출력
alert() 알림창 출력
document.write() 화면 출력

4. 연산자

let a = 10;
let b = 20;

console.log(a + b);
연산자 설명
+ 더하기
- 빼기
* 곱하기
/ 나누기

5. 비교 연산자

        10 == "10"   // true

        10 === "10"  // false

        10 != 5      // true
연산자 설명
== 값 비교
=== 값 + 자료형 비교
!= 같지 않음

14. Fetch API

fetch("/data")

.then(res => res.json())

15. AJAX

const xhr =
new XMLHttpRequest();

xhr.open(
  "GET",
  "/data"
);

xhr.send();

페이지 새로고침 없이 데이터를 주고받는다.

서버와 데이터를 주고받을 때 사용하는 형식이다.

💡 핵심 요약

  • JavaScript는 웹 페이지의 동작과 기능을 담당한다.
  • 변수는 let, const를 사용하여 선언한다.
  • 자료형에는 Number, String, Boolean, Array, Object 등이 있다.
  • 조건문(if, switch)과 반복문(for, while)으로 프로그램 흐름을 제어한다.
  • 함수(Function)는 코드를 재사용하기 위해 사용한다.
  • 이벤트(Event)는 클릭, 입력 등 사용자 행동에 반응한다.
  • DOM(Document Object Model)을 이용해 HTML 요소를 선택하고 수정할 수 있다.
  • 배열(Array)과 객체(Object)를 사용하여 데이터를 관리한다.
  • ES6 문법(화살표 함수, 템플릿 리터럴, 구조 분해 할당)을 지원한다.
  • Fetch API와 AJAX를 이용해 서버와 비동기 통신을 수행한다.
  • Promise와 async/await를 사용하여 비동기 코드를 효율적으로 작성한다.
  • JSON(JavaScript Object Notation)은 서버와 데이터를 주고받는 대표적인 형식이다.
