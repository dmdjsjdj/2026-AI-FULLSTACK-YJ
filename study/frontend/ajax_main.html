1. 비동기 통신

비동기 통신은 페이지를 새로고침하지 않고 서버와 데이터를 주고받는 방식이다.

방식 설명
동기(Synchronous) 작업이 끝날 때까지 대기
비동기(Asynchronous) 다음 작업을 먼저 수행 가능

2. AJAX

AJAX(Asynchronous JavaScript And XML)는 JavaScript를 이용하여 서버와 비동기적으로 데이터를 주고받는 기술이다.

  • 페이지 새로고침 없음
  • 빠른 사용자 경험 제공
  • 실시간 데이터 처리 가능

3. XMLHttpRequest

const xhr = new XMLHttpRequest();

xhr.open("GET", "/data");

xhr.send();

xhr.onload = function(){

  console.log(xhr.responseText);

};

XMLHttpRequest는 AJAX 통신을 위한 전통적인 객체이다.

4. JSON

JSON(JavaScript Object Notation)은 서버와 데이터를 주고받기 위한 대표적인 데이터 형식이다. 

{
  "name":"Yejin",
  "age":24
}
메서드 설명
JSON.parse() 문자열 → 객체
JSON.stringify() 객체 → 문자열

5. Fetch API

Fetch API는 XMLHttpRequest보다 간단하게 서버 통신을 수행할 수 있는 최신 방식이다. 

fetch("/data")

.then(response => response.json())

.then(data => {

  console.log(data);

});

6. Promise

Promise는 비동기 작업의 성공 또는 실패 결과를 처리하기 위한 객체이다. 

const promise = new Promise(
  (resolve,reject)=>{

    resolve("성공");

  }
);

promise.then(result=>{

  console.log(result);

});
메서드 설명
then() 성공 처리
catch() 실패 처리
finally() 마무리 작업

7. Async / Await

Promise를 더욱 직관적으로 사용할 수 있도록 만든 문법이다. 

async function getData(){

  const response =
  await fetch("/data");

  const data =
  await response.json();

  console.log(data);

}
키워드 설명
async 비동기 함수 선언
await 작업 완료까지 대기

💡 핵심 요약

  • 비동기 통신은 페이지 새로고침 없이 서버와 데이터를 주고받는다.
  • AJAX는 비동기 통신 기술이다.
  • XMLHttpRequest는 전통적인 AJAX 통신 방식이다.
  • JSON은 서버와 데이터를 주고받는 대표적인 데이터 형식이다.
  • Fetch API는 최신 비동기 통신 방식이다.
  • Promise는 비동기 작업 결과를 처리한다.
  • Async / Await는 Promise를 더 쉽게 사용하기 위한 문법이다.
