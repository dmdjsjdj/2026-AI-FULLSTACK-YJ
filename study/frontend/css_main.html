1. CSS 기본 문법

CSS(Cascading Style Sheets)는 웹 페이지의 디자인과 레이아웃을 담당한다. 

h1{
  color:blue;
}
구성 설명
Selector 선택자
Property 속성
Value 값

2. CSS 적용 방법

<link rel="stylesheet" href="style.css">
        
<style>
h1{
  color:red;
}
</style>
        
<h1 style="color:red">
방법 설명
Inline 태그 내부 적용
Internal style 태그 사용
External 외부 css 파일 사용

3. 선택자(Selector)

p{
  color:red;
}

.box{
  color:blue;
}

#title{
  color:green;
}
선택자 설명
태그 선택자 p
클래스 선택자 .box
아이디 선택자 #title

4. Box Model

.box{
  margin:20px;
  border:1px solid black;
  padding:10px;
}
속성 설명
margin 바깥 여백
border 테두리
padding 안쪽 여백
content 실제 내용 영역

5. Display

display:block;
display:inline;
display:inline-block;
display:none;
값 설명
block 한 줄 전체 차지
inline 내용만큼 차지
inline-block 크기 지정 가능
none 요소 숨김

6. Position

position:static;
position:relative;
position:absolute;
position:fixed;
값 설명
static 기본 위치
relative 현재 위치 기준
absolute 부모 요소 기준
fixed 화면에 고정

7. Flexbox

.container{
  display:flex;
}
        
justify-content:center;
align-items:center;
속성 설명
display:flex Flex 활성화
justify-content 가로 정렬
align-items 세로 정렬

8. Animation

@keyframes move{

  from{
    left:0;
  }

  to{
    left:200px;
  }

}
        
animation:move 2s infinite;

Animation은 요소에 움직임이나 효과를 적용할 때 사용한다.

9. Bootstrap

<link
href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/css/bootstrap.min.css"
rel="stylesheet">
        
<button class="btn btn-primary">
버튼
</button>
클래스 설명
container 레이아웃 컨테이너
row 행
col 열
btn 버튼

💡 핵심 요약

  • CSS는 웹 페이지의 디자인을 담당한다.
  • 선택자를 사용하여 원하는 요소를 선택한다.
  • Box Model은 margin, border, padding, content로 구성된다.
  • Display는 요소의 배치 방식을 결정한다.
  • Position은 요소의 위치를 지정한다.
  • Flexbox는 레이아웃 정렬에 사용된다.
  • Animation은 움직임을 표현한다.
  • Bootstrap은 UI 프레임워크이다.
