1. HTML 기본 구조

HTML(HyperText Markup Language)은 웹 페이지의 구조를 만드는 마크업 언어이다. 

        <!DOCTYPE html>
        <html>
        <head>
            <title>문서 제목</title>
        </head>
        <body>

        </body>
        </html>
태그 설명
html 문서 전체 영역
head 설정 정보
body 화면에 표시되는 내용

2. 텍스트 태그

태그 설명
h1 ~ h6 제목 태그
p 문단 태그
br 줄바꿈
hr 구분선
strong 강조 
        <h1>제목</h1>
        <p>문단입니다.</p>
        <br>
        <hr>
        <strong>강조</strong>

3. HTML 주석

주석(Comment)은 코드에 설명을 작성할 때 사용하며 브라우저에는 표시되지 않는다. 

          <!-- 주석입니다 -->

4. 링크 태그

        <a href="https://google.com">
        구글 이동
        </a>
  • href : 이동할 주소
  • target="_blank" : 새 창 열기

5. 이미지 태그

        <img src="cat.jpg" alt="고양이">
속성 설명
src 이미지 경로
alt 대체 텍스트

순서 있는 목록

7. 테이블 태그

        <table border="1">

          <tr>
            <th>이름</th>
            <th>나이</th>
          </tr>

          <tr>
            <td>홍길동</td>

태그 설명
table 테이블 생성
tr 행(Row)
th 제목 셀
td 데이터 셀

8. Form 태그

          <form action="/login">

            <input type="text">

            <input type="password">

            <input type="radio">

            <input type="checkbox">

type 설명

password 비밀번호 입력
radio 단일 선택
checkbox 다중 선택
submit 폼 전송

10. div / span

11. 시맨틱 태그

        <header></header>
        <nav></nav>
        <main></main>
        <section></section>
        <article></article>
        <footer></footer>

HTML5에서 의미를 가진 태그를 사용하여 문서 구조를 명확하게 표현한다.

  • 가독성 향상
  • SEO 최적화
  • 유지보수 편리

12. 전역 속성 (Global Attribute)

대부분의 HTML 태그에서 공통적으로 사용할 수 있는 속성이다. 

        <div id="box1" class="container">
          내용
        </div>
속성 설명
id 고유 식별자
class 그룹 지정
style 인라인 스타일
title 툴팁 표시
hidden 요소 숨김

엔티티 결과

14. iframe 태그

다른 웹 페이지를 현재 페이지 안에 삽입할 수 있다. 

        <iframe
          src="https://www.youtube.com"
          width="500"
          height="300">
        </iframe>

15. meta 태그

웹 페이지의 설정 정보를 정의한다. 

        <meta charset="UTF-8">

        <meta
        name="viewport"
        content="width=device-width, initial-scale=1.0">
속성 설명
charset 문자 인코딩 설정
viewport 반응형 웹 설정

16. HTML5 입력 타입

HTML5에서는 다양한 입력 타입을 제공한다. 

        <input type="email">

        <input type="number">

        <input type="date">

        <input type="file">
type 설명
email 이메일 입력
number 숫자 입력
date 날짜 선택
file 파일 업로드

💡 핵심 요약

  • HTML은 웹 페이지의 구조를 만드는 마크업 언어이다.
  • head는 설정 정보, body는 화면 내용을 담당한다.
  • 텍스트, 링크, 이미지, 목록 태그를 사용해 콘텐츠를 구성한다.
  • table은 표를 만들고 form은 사용자 입력을 처리한다.
  • div는 블록 요소, span은 인라인 요소이다.
  • 시맨틱 태그는 문서 구조를 의미 있게 표현한다.
  • id와 class는 CSS와 JavaScript에서 자주 사용된다.
  • meta 태그는 문서 환경을 설정한다.
  • HTML5는 다양한 입력 타입과 멀티미디어 기능을 제공한다.
