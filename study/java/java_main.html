1. Java 소개

Java는 객체지향 프로그래밍(Object-Oriented Programming) 언어이다. 운영체제에 상관없이 JVM(Java Virtual Machine) 위에서 실행되므로 플랫폼 독립성을 가진다. 

            public class Main {

            public static void main(String[] args) {

                System.out.println("Hello Java");

            }

            }
구성 요소 설명
JDK 개발 도구
JRE 실행 환경
JVM Java 프로그램 실행

2. 변수와 자료형

변수는 데이터를 저장하기 위한 메모리 공간이다. 자료형(Data Type)은 저장할 데이터의 종류를 의미한다. 

            int age = 20;
            double score = 95.5;
            char grade = 'A';
            String name = "Yejin";
자료형 설명
int 정수
double 실수
char 문자
String 문자열

3. 연산자

연산자는 데이터를 계산하거나 비교하기 위해 사용한다.

종류 예시
산술 연산자 +, -, *, /, %
비교 연산자 ==, !=, >, <
논리 연산자 &&, ||, ! 
            int a = 10;
            int b = 3;

            System.out.println(a + b);
            System.out.println(a % b);

4. 조건문

조건에 따라 실행 흐름을 분기한다. 

            int score = 80;

            if(score >= 60){

            System.out.println("합격");

            }else{

            System.out.println("불합격");

            }
  • if : 조건이 참일 때 실행
  • else : 조건이 거짓일 때 실행
  • switch : 여러 조건 분기

5. 반복문

동일한 코드를 여러 번 실행할 때 사용한다. 

            for(int i = 1; i <= 5; i++){

            System.out.println(i);

            }
반복문 설명
for 횟수 반복
while 조건 반복
do-while 최소 1회 실행

6. 배열

같은 자료형의 데이터를 여러 개 저장하는 구조이다. 

            int[] numbers = {10,20,30};

            System.out.println(numbers[0]);
  • 인덱스는 0부터 시작
  • 배열 크기는 생성 후 변경 불가

7. 메서드

특정 기능을 하나로 묶어 재사용할 수 있게 만든 코드 블록이다. 

            public static int add(int a, int b){

            return a + b;

            }
구성 요소 설명
반환형 return 값의 자료형
메서드명 기능 이름
매개변수 전달받는 값

8. 클래스와 객체

객체지향 프로그래밍에서 클래스(Class)는 객체를 만들기 위한 설계도이고, 객체(Object)는 클래스로부터 생성된 실제 인스턴스이다. 

            class Student {

            String name;
            int age;

            }

            Student s1 = new Student();
용어 설명
클래스 객체를 생성하기 위한 설계도
객체 클래스로 생성된 실체
인스턴스 메모리에 생성된 객체

9. 생성자

생성자는 객체가 생성될 때 자동으로 호출되는 특별한 메서드이다. 

            class Student {

            Student() {

                System.out.println("객체 생성");

            }

            }
  • 클래스 이름과 동일
  • 반환형 없음
  • 객체 생성 시 자동 호출

10. static

static 멤버는 객체 생성 없이 클래스 이름으로 접근할 수 있다. 

            class Test {

            static int count = 0;

            }

            System.out.println(Test.count);
구분 특징
instance 객체 생성 후 사용
static 객체 생성 없이 사용

11. 상속

상속(Inheritance)은 기존 클래스의 기능을 물려받아 새로운 클래스를 만드는 것이다. 

            class Animal {

            void move() {

                System.out.println("이동");

            }

            }

            class Dog extends Animal {

            }
  • 코드 재사용 가능
  • 유지보수 용이
  • extends 키워드 사용

12. 다형성

하나의 부모 타입으로 여러 자식 객체를 다룰 수 있는 특징이다. 

            Animal animal = new Dog();
종류 설명
업캐스팅 부모 타입으로 참조
다운캐스팅 자식 타입으로 변환

13. 추상 클래스

객체를 생성할 수 없는 클래스이며 공통 기능을 정의하기 위해 사용한다. 

            abstract class Animal {

            abstract void sound();

            }
  • abstract 키워드 사용
  • 객체 생성 불가
  • 상속 후 구현 필요

14. 인터페이스

클래스가 반드시 구현해야 하는 기능의 규칙을 정의한다. 

            interface Animal {

            void sound();

            }

            class Dog implements Animal {

            public void sound() {

                System.out.println("멍멍");

            }

            }
추상 클래스 인터페이스
단일 상속 다중 구현 가능
일반 메서드 포함 가능 규칙 정의 중심

15. 예외 처리

예외(Exception)는 프로그램 실행 중 발생하는 오류 상황이다. 예외 처리를 통해 프로그램이 비정상 종료되는 것을 방지할 수 있다. 

            try{

            int result = 10 / 0;

            }catch(Exception e){

            System.out.println("오류 발생");

            }
키워드 설명
try 예외 발생 가능 코드
catch 예외 처리
finally 항상 실행
throw 예외 발생

16. 컬렉션 프레임워크

배열보다 유연하게 데이터를 저장하기 위한 자료구조 모음이다. 

            ArrayList list = new ArrayList<>();

            list.add("Java");
            list.add("Spring");
컬렉션 특징
ArrayList 순서 O, 중복 O
LinkedList 삽입/삭제 유리
HashSet 중복 X
HashMap Key-Value 저장

17. Generic

Generic은 클래스나 메서드에서 사용할 자료형을 일반화하는 기능이다. 

            ArrayList names =
            new ArrayList();
  • 컴파일 시 타입 검사 가능
  • 형변환 감소
  • 코드 재사용 증가

18. 파일 입출력 (IO)

Java는 파일을 읽고 쓰기 위한 다양한 입출력 클래스를 제공한다. 

            FileWriter fw =
            new FileWriter("test.txt");

            fw.write("Hello Java");

            fw.close();
클래스 설명
File 파일 정보 관리
FileReader 파일 읽기
FileWriter 파일 쓰기
BufferedReader 버퍼 기반 읽기

  • 컬렉션과 Generic을 통해 효율적인 자료 관리를 수행한다.
